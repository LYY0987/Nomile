# Nomile v0.1.0 · 初版

Windows 批量重命名工具的首个可安装版本。规则在 Rust 侧算一次，预览与执行共用同一份计划，界面只负责呈现。

**下载**：`Nomile_0.1.0_x64-setup.exe`（推荐，NSIS 安装）/ `Nomile_0.1.0_x64_en-US.msi`

## 亮点

### 规则与预览
- 17 种规则自由叠加、可上下调序：查找替换、序号、模板、大小写、前后缀、清理、按位置截取、指定位置插入、删除括号内容、清除副本标记、限制长度、设置扩展名、统一分隔符、剥掉固定前后缀、插入时间，以及 AI 命名方案、AI 按内容命名
- 改任何一条规则立刻重算；列表并排显示「原名 → 新名」，只高亮真正改动的片段
- 新增文件类型列（图片 / 文档 / 音频 / 视频 / 压缩包 / 表格 等），一眼分辨混在一起的素材
- 常用 6 条固定快捷区 + 分组规则库；规则栈可另存为「我的预设」，随时下拉切换

### 安全重命名
- 目标重名默认自动加序号，或选择跳过；**没有覆盖选项**
- 两阶段执行 + WAL 撤销日志：执行后底部弹出带倒计时的撤销入口，倒计时结束仍可在「历史记录」里撤销
- 撤销前比对 `size + mtime`，判断文件是否在执行后被外部改动，被动过的直接跳过

### 命名素材
- 元数据变量：EXIF 拍摄时间、相机、音视频标题 / 艺术家 / 专辑 / 轨道 / 时长 / 尺寸，按需读取（规则里没用到就不打开文件）
- 来源支持目录与散选文件；目录模式下可按子目录 / 隐藏项 / 文件夹 / 包含模式 / 排除模式收紧范围

### AI 命名（需自备服务）
- 自然语言 → 母模板：一句话拆成可查看的槽位组合，而不是硬塞进固定规则
- 按内容命名：读取文本、PDF、DOCX、PPTX、XLSX/XLS 后逐文件起名；AI 只回文件名，不碰文件
- 配置内置 Ollama 等预设，也支持 OpenAI 兼容的自定义 Base URL + 模型；API Key 存入系统凭据管理器

### 体验
- 明暗主题切换、窗口尺寸记忆、全新矢量应用图标
- 界面操作补齐图标，规则区可滚动，长规则栈不再挤压可视区

## 安装

1. 运行 `Nomile_0.1.0_x64-setup.exe`，或双击 `.msi`
2. 若出现 SmartScreen「未知发布者」，选择「更多信息 → 仍要运行」（安装包未做代码签名）
3. 系统要求 Windows 10 / 11 x64，WebView2 运行时（Win11 自带，Win10 若缺失会由安装包提示）

## 已知限制

- 仅支持 Windows；两阶段改名与撤销日志按 Windows 路径与文件语义实现
- AI 功能需要自行配置服务，不内置 Key，离线环境不可用
- 首次从小尺寸图标切换后，若桌面仍显示旧图标，属 Windows 图标缓存，重建图标缓存或重新登录后刷新
